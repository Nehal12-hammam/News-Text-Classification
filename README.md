# News Text Classification with Deep Neural Networks

## 📌 Overview
A multi-class news text classification system built using deep neural networks. The project implements a complete Natural Language Processing (NLP) pipeline to preprocess textual data, extract meaningful features, and classify articles into distinct categories.

## 🛠️ Key Features & Pipeline
- **Text Preprocessing & Tokenization:** Utilized NLTK and SpaCy for tokenization, lowercasing, stop-word removal, lemmatization, and sequence padding.
- **Embeddings & Feature Engineering:** Implemented custom word embeddings and vectorization to transform text data into numerical representations suitable for neural networks.
- **Deep Neural Network Architecture:** Designed and trained multi-layer DNN models using TensorFlow and Keras, optimized with hyper-parameter tuning for robust classification performance.

## 💻 Technologies Used
- **Language:** Python
- **Deep Learning Frameworks:** TensorFlow, Keras
- **NLP & Text Processing:** NLTK, SpaCy
- **Core Concepts:** Deep Neural Networks (DNN), Hyper-parameter Tuning
